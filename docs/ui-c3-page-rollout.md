# C3 逐页落实与功能适配

日期：2026-11-06。状态：逐页落实与定向验证完成。

用户要求：以已经批准的 `design/ui-redesign/color.html` 为基准逐页落实，整体布局与设计稿基本一致；设计稿没有覆盖的现有必要功能，沿用其视觉规则适配，不能删减业务功能。本轮不再把“主题颜色一致”作为页面还原的验收结论。

## 对照原则

- 核对信息顺序、主次区域、列表形式、编辑方式、操作位置、留白与状态反馈。使用桌面 1440 px 和窄屏 390 px 截图进行实际检查。
- C3 浅灰画布、白色面板、直角导航、清亮蓝主操作保持统一。英文层级标签由共享 `PageHeader` 提供。
- 后续用户意见优先于静态稿：考试详情三卡无顶部纯色条；注册与改密的密码要求独立放在字段和提交按钮之间。
- 真实接口不提供的统计、编号、科目、题型分布等，不用示例数字补齐；使用真实可用信息或明确空值提示。
- 业务接口与权限规则保持，必要时仅为已存在的服务端筛选能力补齐前端参数。

共享层补齐 30 px 页面标题与英文眉题、204 px 侧栏和桌面 32 px 内容边距。教师与管理员导航按“考试工作／考前准备／教学组织或系统管理”分组，保留账号入口；独立答卷回看归属考试历史，评分路由归属阅卷工作台。评分工作区隐藏全局侧栏，正文净宽最多 1248 px，并保留身份与退出入口。

## 公共与账号页面

| 页面 | 原差异 | 落实与保留功能 |
|---|---|---|
| 登录 | 左侧表单、右侧使用说明，与稿的区域顺序不符 | 恢复浅蓝介绍区在左、登录表单在右；保留角色账号说明、登录错误、过期会话提示与自动回跳 |
| 注册 | 表单与标题共用外部卡片，返回入口在底部 | 760 px 居中限宽、标题与返回入口紧邻表单顶部，白色表单独立成卡；原密码要求、强度匹配、申请成功状态保留 |
| 联系方式 | 额外右侧说明栏、重复面板标题 | 680 px 单列表单；安全核验与账号协助说明移至卡片下部；当前密码核验、未知保存结果后的重新读取保留 |
| 修改密码 | 额外右侧说明栏、重复面板标题 | 680 px 单列表单；独立密码要求仍在字段与保存按钮之间；首次强制改密、会话清理及未知结果确认保留 |
| 申请进度 | 状态和提交资料拆成大块，视觉重心分散 | 760 px 状态卡内依次显示状态标题、审核说明、提交资料和后续入口；拒绝原因、原资料更正表单及重新提交保留 |

申请页采用现有“学生注册申请”标题，待审／已通过／拒绝状态使用服务端数据。设计稿未覆盖的手机号、审核时间与更正流程继续显示，不杜撰学年或申请记录。

### 逐页视觉核对

- 已按 C3 核对 30 个页面场景（包含管理员首页及交卷完成态），产出 1440 px / 390 px 产品截图，并目检各组主要页面。宽表格保留列内容，在表格内部滚动，不撑开整页。
- 本机交互对照入口：`.local/c3-page-review/index.html`。可切换 30 个页面及两种宽度；左侧为当前前端测试数据截图，右侧为批准稿。120 张对应图片已逐一验证可加载。参考图只截取产品区域，去掉评审工具条，未改变设计内容。
- 学生作答和阅卷采用各自专注布局；管理和编辑扩展功能置于稿式侧栏、折叠区或次要操作。错题完整选项仍可展开；管理员保留全宽进度与改派，不能进入评分。
- 可见业务字段及状态以接口为准。学生考试状态页签明确仅筛选当前页；成绩分项、考试提交比例、班级年级等接口未提供的信息已在分组文档列出，不用虚构值补齐。

所有截图、对照索引和测试输出位于忽略的 `.local/`。不对真实考试或用户账号执行写操作，未做生产部署，也未运行后端全量测试。本轮验收目标为布局、视觉层级与必要功能适配基本一致，不宣称与静态稿逐像素相同。
