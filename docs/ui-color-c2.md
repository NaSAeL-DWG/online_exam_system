# UI 配色方案 C2：增加白底比例

日期：2026-11-04。状态：修订完成，等待用户审核。生产界面与后端未修改。

## 修改依据

用户反馈 C1 仍显灰暗、单调，随后明确方向为“让白底区域更多一些”。据此提高整个画面的白底覆盖面，减轻大块灰底和深色块，以浅灰保留必要分区，同时提亮蓝色操作与定位元素。

已按用户要求在 Chrome 查看 [Pintia 考试练习页](https://pintia.cn/problem-sets/dashboard)。参考其白色导航、白色内容卡片、局部浅灰间隔及清晰蓝色操作的组合。项目继续沿用已通过的灰度布局和考试任务层级。

## 具体变化

| 区域 | C1 | C2 |
|---|---|---|
| 全局工作区底色 | `#F4F4F4` | `#FFFFFF`，增加连续白底面积 |
| 侧栏 | 近白灰底 | 白底，导航图标采用清亮蓝 |
| 评审栏 | 深灰底白字 | 白底深色文字，C2 标识及操作用蓝色 |
| 当前导航项 | 深蓝实色底 | 极浅蓝底、深蓝文字、蓝色内侧定位线 |
| 考试状态卡片 | 浅蓝整块填充 | 白底，以蓝色顶边和倒计时强调 |
| 主要操作 | 深蓝 `#1F456F` | 清亮蓝 `#2164CE` |
| 控件默认边框 | `#7A7A7A` | `#8C8C8C`，降低视觉重量并保持可辨识性 |
| 常规提示 | 浅灰 `#F4F4F4` | 更接近白色的 `#FAFAFA` |

浅灰仍用于表头、公式、答案说明等局部区域；已结束考试的灰色卡片、已标记待检查的深灰底白字，以及成功／预警／失败语义继续保留。

- 四个主色族和辅助灰均为 10 阶，明度依序递减。
- Chrome 1440 px 下检查 29 个默认视图，未发现整页横向溢出或常规可见文字对比度不足。
- 390 px 下检查考试详情、作答、评分和注册，以及作答时间预警、保存失败，共 6 个页面／状态组合；检查通过。

- 同一窗口、同一考试详情状态下，C1 与 C2 的主要布局边界、位置和尺寸测量一致。
- 主要变更为颜色与背景分布，原有交互和生产业务实现保持不变。
