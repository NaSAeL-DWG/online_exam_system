# 迭代 3 接口契约

状态：2026-10-02 实施中。学生只读取自己的有效作答；本轮不判分、不开放标准答案、解析及成绩。HTTP 测试边界为 FastAPI + 真实 PostgreSQL / Redis，逐行为 red → green。

## 学生考试

- `GET /api/student/exams?page=1&page_size=20&q=`：返回既有 `Page`，仅公开已发布考试及本人已有资格的已发布／已取消考试，包含显式撤销提示。
- `GET /api/student/exams/{exam_id}`：返回下面摘要。浏览详情不建立资格、不消耗次数，也不返回题目。

摘要字段：`id,title,description,audience_type,status,start_at,end_at,duration_seconds,max_attempts,total_score,server_now,participant_status,cancelled_reason,used_attempts,remaining_attempts,current_attempt_id,current_attempt_status,can_start,unavailable_reason`。时间 ISO UTC；分值为十进制字符串；未建公开资格 `participant_status=null`。`unavailable_reason` 为稳定错误码或 null。撤销资格优先显示 `PARTICIPANT_CANCELLED`，整场取消显示 `EXAM_CANCELLED`。

`current_attempt_id/status` 优先指向进行中作答，否则指向最近有效 SUBMITTED 收据；VOID 一律排除。查看已提交收据不依赖 `can_start`。取消的未配置草稿可以返回 `start_at/end_at/duration_seconds=null`。

## 开始、读取与页面激活

- `POST /api/student/exams/{exam_id}/attempts`，JSON `{}`：显式开始；同场存在未到期作答即返回它，不额外消耗次数；先收尾已到期作答，再决定是否还能开始。返回 `AttemptDetail`，不发页面令牌。
- `GET /api/student/attempts/{attempt_id}`：返回本人服务器当前作答；只供本人、资格有效、考试未取消、作答非 VOID 读取。到期未收尾会先超时提交。题目仅在本轮合法作答中读取。
- `POST /api/student/attempts/{attempt_id}/activate`，JSON `{ "page_token": "原随机令牌（可省略）" }`：原有效令牌为刷新恢复，令牌代次不变；省略令牌为主动接管，生成随机令牌及递增代次，旧令牌立即失效。传入过期令牌返回 `PAGE_TAKEN_OVER`，不静默接管。返回 `AttemptActivation` = `AttemptDetail` 加 `page_token,token_generation`。提交后不允许激活。

`AttemptDetail`：`id,exam_id,exam_title,attempt_no,status,started_at,deadline_at,submitted_at,effective_submitted_at,submission_type,grading_status,server_now,version,token_generation,questions`。`grading_status` 本轮始终 `PENDING`。题目数组按持久展示顺序排列，各项 `id,type,content,options,score,display_order,answer`；选项 `{id,content}` 按持久选项顺序；答案 `{id,answer_data,version,answered_at}`。`answer_data` 空答 null；不返回参考答案、解析、分类、来源、评分状态、得分或任何令牌摘要。

已提交作答仅返回提交收据，`questions=[]`，当前迭代不开放答案回看。前端交卷后清理答题内容与本地草稿；历史回看须在迭代 5 通过公布和 `allow_review` 双重授权。

前端须在每次激活前取得按用户／作答命名的 Web Lock，以 BroadcastChannel 协调主动接管。复制标签页即使复制 sessionStorage 也不能两页同时取得写锁；原令牌只用于刷新恢复。后端令牌摘要+代次是接管的最终写权限依据。

## 保存与交卷

- `PUT /api/student/attempts/{attempt_id}/answers/{answer_id}`：`{page_token,token_generation,version,answer_data}`；返回答案 `{id,answer_data,version,answered_at}`。答案版本每次成功保存递增；任何题型可用 null 清空。
- 单选 `answer_data=["选项UUID"]`，最多一个；多选 UUID 数组可空，禁止重复、未知 UUID；判断严格 boolean（false 合法）；简答严格字符串，纯文本，最多 20000 字，空白规范为空答 null。禁止 bool／数字／字符串被自动强制转换为其他题型。
- `POST /api/student/attempts/{attempt_id}/submit`：`{page_token,token_generation,confirm_unanswered:false}`；空题未确认返回 409 `UNANSWERED_CONFIRMATION_REQUIRED`。确认后可提交；返回 `AttemptDetail`。重复请求返回既有提交事实，不重复计次；到期时无须空题确认，仅交服务器已经保存的答案。

全部写接口需要登录 Cookie 和 `X-CSRF-Token`。保存和提交使用相同加锁顺序，锁后重新检查身份、资格、状态、令牌代次、截止时间。截止后保存立即返回 `ATTEMPT_EXPIRED`，不接受离线补传。

错误：401 认证类沿用现有契约；403 `PARTICIPANT_REQUIRED/PARTICIPANT_CANCELLED/PAGE_TAKEN_OVER`；404 `EXAM_NOT_FOUND/ATTEMPT_NOT_FOUND/ANSWER_NOT_FOUND`；409 `EXAM_CANCELLED/EXAM_NOT_STARTED/EXAM_ENDED/ATTEMPTS_EXHAUSTED/ATTEMPT_EXPIRED/ATTEMPT_SUBMITTED/UNANSWERED_CONFIRMATION_REQUIRED/VERSION_CONFLICT`；400 `INVALID_ANSWER`；422 字段格式错误沿用 `VALIDATION_ERROR`。

## 教师取消与图片

- `POST /api/staff/exams/{exam_id}/cancel`：`{version,reason}`，非空原因必填；返回既有 `ExamDetail` 加 `cancelled_at,cancelled_reason`。整场不可恢复；全部作答同事务 VOID 并记录审计。
- `GET /api/assets/{asset_id}`：教师沿用共享授权。学生只可读取其未到期 IN_PROGRESS 作答快照题干／选项实际引用的资源；解析、题库、他人和已提交／VOID／撤销／取消资源不可读。返回 private,no-store 图片。

## 后台公开业务入口

`app.modules.attempt.service.timeout_attempt(session, attempt_id) -> bool`：拥有事务，与 HTTP 交卷复用同一状态转换；已提交、VOID、未到期返回 false；到期写 SUBMITTED / TIMEOUT / PENDING。停用账号仍须正常超时提交，但撤销资格／取消考试绝不复活。

`app.modules.attempt.service.scan_due_attempt_ids(session, limit=100) -> list[UUID]`：仅返回到期 IN_PROGRESS IDs，供独立 worker 扫描补偿。worker 为每次业务调用使用独立 Session，扫描 Session 结束后再处理。

开始成功后经 `app.core.attempt_queue.enqueue_attempt_timeout(attempt_id, deadline_at)` 投递。队列仅加速处理；异常保留已提交业务，由 PostgreSQL 到期扫描补偿。后台本轮不生成分数或伪造 GRADED。
