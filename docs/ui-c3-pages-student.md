# C3 学生页面逐页落实记录

日期：2026-11-06。参考：`design/ui-redesign/color.html` 学生页面及相关 C3 样式。本文记录实际页面的结构调整、设计外业务能力的适配和已执行验证，不声称像素完全一致。

## 范围与原则

- 学生工作台 `StudentHomeView.vue` 已在 a8558a2 完成，本次仅回归核对，没有重写。
- 页面继续通过既有 API 读取真实数据。设计稿中的虚拟编号、题量、及格线和题型分数不直接复制到产品。
- 详情概览三卡均保留普通细边框，不增加顶部纯色条；已标记待检查按钮保留深灰底、白字和实心旗。
- 公共 PageHeader / SurfacePanel / 导航与整体间距由共享改动统一处理；本次学生样式局限于页面 scoped CSS 和学生专属题目组件。

## 设计未覆盖或后端未提供的信息

- 考试列表 API 只支持名称搜索和分页，状态页签明确作用于当前页；总量大于一页时显示范围说明，计数不冒充全库统计。取消和资格撤销仍保留在全部页签中。
- 考试详情 API 不提供题量、题型和及格线，因此第三卡只展示真实满分，并提示进入作答后查看题量题型；不复制稿中“20 题”“及格线 60 分”。
- 成绩详情 API 不提供按题型分项成绩，也不为美化页面额外读取未获许可的答卷，左主栏以真实本场信息替代设计稿的四条虚拟得分条。
- 错题的掌握状态与笔记共享一次保存请求，侧栏更改后有未保存说明，通过“保存学习标记”确认写入。
- 分析总分趋势仍遵循后端现有口径：已公布有效成绩；题型和知识点仅统计允许回看的考试。页面说明明确区分这两种样本。

## 目检与剩余边界

已对照设计截图目检列表、作答与错题详情，校正了考试行过高、表格操作缺少描边、作答内容过宽、错题详情重复选项导致笔记过深的问题。需要保留的真实业务信息使部分卡片高度和操作数量与静态稿不同。表格在 390px 屏内采用表格容器横向滚动，不撑开整页。没有使用设计稿中的虚拟成绩填补缺失数据。
