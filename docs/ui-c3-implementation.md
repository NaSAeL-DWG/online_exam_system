## 实施约束

- 画布 `#F6F7F9`，内容与导航为白色；主要操作使用 Blue 600 `#2164CE`。
- 侧栏导航圆角严格为 0，选中态使用 3 px 矩形提示条。其他容器与控件采用 0–4 px 小圆角。
- 已标记待检查按钮保持深灰背景、白色文字与实心旗帜，不占用预警色。
- 输入焦点强调自身边框；下拉选项使用统一组件与浮层阴影。
- 后端仍负责权限、作答期限、自动提交与成绩规则。前端不伪造统计或尚未提供的字段。
- 复用现有组件与依赖，验证范围随实际变更选择，保留必要的真实业务回归。

## 组件与数据约定

- `styles/tokens.css` 定义色阶与语义变量；`design/theme.ts` 为 Naive UI 提供对应实际色值。新页面应复用这两层，避免引入旧绿色主题值。
- `AppSelect.vue` 统一下拉样式、真实焦点的 combobox 语义、选项列表、搜索与键盘操作。基础组件测试覆盖 Naive UI 内部触发器适配；升级依赖时应运行该测试。
- `LoadingSkeleton.vue` 支持 `list`、`table`、`detail`，白光每 3.2 秒间歇横扫，遵循减少动态效果偏好。
- 学生首页已按 2026-11-06 复核恢复“当前考试＋接下来考试／学习记录双栏＋提醒”，当前考试及接下来两场从近期 20 条记录中挑选；“全部考试”进入完整分页列表。个人倒计时与进度读取服务器作答快照；成绩、错题读取现有接口。教师首页显示本人待阅与阅卷中任务的服务端总数。
- 考前接口尚未提供题量及题型分布。因此试卷结构卡显示真实满分，并提示“题量与题型进入作答后查看”。本次没有新增后端字段或提前暴露考试快照。
- 退出作答前尝试保存；提醒明确区分服务器已保存答案与未同步本地修改。退出不暂停计时，自动交卷仍由原后端能力决定。认证失效直接回到登录，不被退出提醒拦截；答卷读取失败仍可返回考试列表。
- 管理员旧阅卷／评分链接回到考试管理，改派能力迁至“阅卷进度与成绩”列表。教师保留阅卷与评分依据更正，后端授权规则没有修改。
