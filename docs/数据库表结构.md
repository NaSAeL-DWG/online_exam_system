# 数据库表结构

状态：以下为完整逻辑模型。迭代 1 已建立身份、审核、教学班和审计表；题库、考试、作答、阅卷等后续表尚未实现。实际迁移与逻辑名称的对应见下文。

依据：[需求规格](./需求规格.md)；术语：[CONTEXT](../CONTEXT.md)。本版替代原始草案，补充考试快照、审核、阅卷任务、评分历史和错题标记。

## 1. 通用约定

- PostgreSQL；SQLModel 表模型配合 SQLAlchemy AsyncSession。表模型、输入模型、响应模型分离，禁止直接序列化带密码或标准答案的整行对象。
- 实体主键采用原生 UUID（16 字节），接口使用标准 UUID 字符串；外键类型一致。
- 时间使用 TIMESTAMPTZ，以 UTC 存储和比较，界面按 Asia/Shanghai 展示。通用实体含 created_at、updated_at；不可变历史只需发生时间。
- 分值使用 NUMERIC(10,1)，应用使用 Decimal，最终题分四舍五入到一位小数。题目满分大于零，评分范围为零到满分。
- 用户、题目、考试和作答使用归档或状态变更保留历史，不级联物理删除。
- creator_id 只记录创建者，不作为教师访问题库、试卷、考试的过滤条件。
- 下文为逻辑字段与约束；跨表规则须在事务内验证，不能当作普通 CHECK 已经保证。

## 2. 身份与教学班

迭代 1 的物理表已由 `backend/migrations/versions/0001_identity_and_classes.py` 建立：逻辑 `user.user_id` 对应 `user_account.id`，其余本节表名及 `audit_event` 与实现一致。采用 UUID、TIMESTAMPTZ、PostgreSQL 原生枚举及 JSONB；审核待处理唯一性由部分唯一索引保证。密码与 Token 不进入公开响应或审计内容。

### user — 用户基础表

| 字段 | 类型／约束 | 含义 |
|---|---|---|
| user_id | UUID PK | 统一用户 ID |
| login_name | VARCHAR UNIQUE NOT NULL | 学生学号、教师工号、管理员预置账号，全局唯一 |
| password_hash | TEXT NOT NULL | Argon2id 哈希 |
| phone_number / email | VARCHAR NOT NULL | 必填联系方式，第一版未验证，不作为自动找回凭据 |
| real_name | VARCHAR NOT NULL | 真实姓名 |
| user_type | STUDENT / TEACHER / ADMIN | 一账号一种角色 |
| status | WAITING_ACTIVATE / ACTIVATED / DEACTIVATED | 等待激活、已激活、停用 |
| email_verified_at / phone_verified_at | TIMESTAMPTZ NULL | 预留验证状态，第一版为空 |
| must_change_password | BOOLEAN | 临时密码登录后强制改密 |
| auth_version | BIGINT DEFAULT 0 | 重置／停用时递增，使旧会话失效 |
| created_at / updated_at | TIMESTAMPTZ | 通用时间 |

角色由服务端控制，学生不能注册为教师／管理员。学号、工号与 login_name 在同一事务保持一致。联系方式不承担唯一登录标识职责，不依赖未验证联系方式合并账号。管理员初始化也提供联系方式和外部配置的密码。

### student_profile / teacher_profile — 资料扩展

| 表 | 字段与约束 |
|---|---|
| student_profile | user_id PK/FK → user；student_no UNIQUE NOT NULL；通用时间 |
| teacher_profile | user_id PK/FK → user；teacher_no UNIQUE NOT NULL；通用时间 |

资料类型须匹配用户角色。学生资料不保存单一 teachingclass 字段，全部班级关系通过成员表表达。

### registration_review — 注册审核历史

id、user_id FK → user、status(PENDING/APPROVED/REJECTED)、submitted_profile JSONB、reviewer_id FK → user NULL、reason TEXT NULL、submitted_at、reviewed_at NULL。

每次申请一条记录，保存审核时的资料快照；部分唯一索引保证每名学生至多一条 PENDING 申请。拒绝不等于停用，拒绝后仍 WAITING_ACTIVATE，可修改并重新申请。审核通过、激活和审计同事务完成。

### teaching_class — 教学班

id、name、description NULL、creator_id FK → user、status(ACTIVE/ARCHIVED)、通用时间。

### class_member — 教学班成员

class_id FK → teaching_class、user_id FK → user、role(STUDENT/TEACHER)、joined_at；联合主键 (class_id,user_id)。

成员角色与用户角色一致。管理员维护班级及教师关联，关联教师维护学生成员；归档班级不能维护成员或用于补入考试名单。移出成员记录审计，不影响既有考试资格。

## 3. 题库与预设试卷

### question — 共享题目

id、creator_id FK → user、type(SINGLE_CHOICE/MULTIPLE_CHOICE/TRUE_FALSE/SHORT_ANSWER)、content TEXT、options JSONB、standard_answer JSONB NULL、explanation TEXT NULL、subject VARCHAR、knowledge_tags JSONB、difficulty(EASY/MEDIUM/HARD)、status(ACTIVE/CLOSED)、version BIGINT、通用时间。

- content、explanation 为 Markdown；科目必填，标签数组可空，难度默认 MEDIUM。
- 选择题 2—8 个选项，每个含稳定 UUID id 与 content；正确答案为选项 ID 数组，单选一个、多选至少两个。
- 判断题为布尔标准答案，简答题参考答案可空；学生简答为纯文本，不执行代码。
- 按题型验证 JSON 结构；version 用于共享编辑冲突检查。
- 关闭后不能新增到试卷或考试草稿，原有引用保留。

### paper — 预设试卷

id、creator_id FK → user、title、description NULL、status(ACTIVE/ARCHIVED)、version BIGINT、通用时间。

### paper_question — 试卷题目关联

id、paper_id FK → paper、question_id FK → question、order_no INTEGER、score NUMERIC(10,1)。

约束：UNIQUE(paper_id,question_id)、UNIQUE(paper_id,order_no)、order_no > 0、score > 0。调序原子完成，避免中间唯一键冲突。

试卷是题目的预设引用集合。已有试卷中的关闭题目可整体复制到新考试但须提示；归档试卷不能创建考试。复制全卷时使用一致的事务视图。

## 4. 考试与独立快照

### exam — 考试

| 字段 | 类型／含义 |
|---|---|
| id / creator_id | PK／创建者 FK → user |
| source_paper_id | FK → paper，仅追踪来源，不用于加载考试内容 |
| title / description | 考试说明 |
| audience_type | PUBLIC / RESTRICTED |
| start_at / end_at | 时间窗口，start_at < end_at |
| duration_seconds / max_attempts | 正整数时长／次数 |
| status | DRAFT / RELEASED / RESULTS_PUBLISHED / CANCELLED |
| allow_review | 是否开放答案、解析和错题 |
| shuffle_questions / shuffle_options | BOOLEAN，默认 false |
| multiple_choice_mode | EXACT / PARTIAL |
| pass_percentage | NUMERIC(5,2)，默认 60，范围 0—100 |
| total_score | 快照题分汇总，不读取原试卷 |
| content_revision / grading_revision | 内容／评分修订号 |
| version | 并发控制版本 |
| released_at / results_published_at | 可空时间 |
| results_withdrawn_at / results_withdraw_reason | 最近撤回结果时间／原因 |
| cancelled_at / cancelled_reason | 取消时间／原因 |
| created_at / updated_at | 通用时间 |

时间上的未开始、进行中、已结束由窗口推导。撤回考试发布返回 DRAFT；撤回结果返回 RELEASED。所有发布、撤回和更正记录 audit_event，不只保留最后一次时间。

### exam_question — 考试快照题目

id、exam_id FK → exam、source_question_id FK → question NULL、source_paper_question_id FK → paper_question NULL、order_no、score、type、content、options JSONB、standard_answer JSONB NULL、explanation NULL、subject、knowledge_tags JSONB、difficulty、grading_revision、通用时间。

- 内容、选项、答案、分类、顺序、分值独立保存，来源 ID 仅追溯用途。
- UNIQUE(exam_id,order_no)；来源非空时 UNIQUE(exam_id,source_question_id)，避免一场考试重复引入同一题。
- 学生答案必须指向此表，不能指向实时 question。
- 有人开始后锁定题干、选项、分值；允许专门更正标准答案／简答评分依据，递增评分版本并保留旧依据审计。
- 来源关联不承担快照生命周期；移除原试卷的题目关联时，可将 source_paper_question_id 置空，不能级联移除考试快照。

### exam_grader — 指定阅卷教师

exam_id FK → exam、teacher_id FK → user、assigned_by FK → user、assigned_at；联合主键 (exam_id,teacher_id)。

含简答题考试发布时至少关联一名激活教师，纯客观题无需指定。发布前配置初始名单，后续异常改派由管理员记录原因处理。

### exam_participant — 考试资格

id、exam_id FK → exam、user_id FK → user、status(ASSIGNED/CANCELLED)、assigned_at、cancelled_at NULL、cancelled_reason NULL、version、通用时间。

- UNIQUE(exam_id,user_id)；索引 (user_id,status,exam_id)。
- 班级／单独／公开首次进入是补入途径，不是持续授权关系，来源明细进入审计。
- 普通补入对已有 ASSIGNED 去重，对 CANCELLED 提示需显式恢复，不能无声复活资格。
- 撤销与废弃全部作答、任务作废同事务完成。恢复不复活旧作答、不重置次数。

## 5. 作答、答案与阅卷

### exam_attempt — 一次作答

| 字段 | 类型／含义 |
|---|---|
| id / exam_participant_id | PK／FK → exam_participant |
| attempt_no | 资格内递增正整数，包含已废弃次数 |
| status | IN_PROGRESS / SUBMITTED / VOID |
| started_at / deadline_at | 开始时间／固定截止时间 |
| last_active_at / submitted_at | 活动时间／实际完成提交事务时间 |
| effective_submitted_at | 手动为收到时间，自动为 deadline_at，避免后台延迟改变业务截止 |
| submission_type | MANUAL / TIMEOUT，可空 |
| grading_status | PENDING / GRADING / GRADED |
| grading_revision | 本答卷目标评分修订号 |
| final_score / graded_at | 本次总分／完成时间，未判完总分为空 |
| active_token_hash / active_token_generation | 激活答题页面令牌摘要／代次 |
| version | 并发控制版本 |
| voided_at / void_reason | 废弃时间／原因 |
| created_at / updated_at | 通用时间 |

- UNIQUE(exam_participant_id,attempt_no)；部分唯一索引保证每个资格至多一条 IN_PROGRESS。
- 对 IN_PROGRESS 的 deadline_at 建部分索引，供到期扫描。
- deadline_at = min(started_at + duration_seconds,end_at)；保存须在截止前由服务端接受。
- 开始、资格撤销、接管、提交、保存使用统一加锁顺序。扫描尚未处理的到期作答由进入接口先收尾，再决定能否新建下一次作答。
- final_score 仅表示本次得分，学生整场最终成绩由最后一次有效提交查询得到。

### stu_answer — 单题答案

id、attempt_id FK → exam_attempt、exam_question_id FK → exam_question、answer_data JSONB NULL、grading_status(PENDING/GRADING/GRADED)、is_correct BOOLEAN NULL、score NUMERIC(10,1) NULL、grader_comment TEXT NULL、graded_by FK → user NULL、grading_method(AUTO/MANUAL) NULL、grading_revision、version、answered_at NULL、graded_at NULL、通用时间。

- UNIQUE(attempt_id,exam_question_id)；事务验证作答与题目属于同一考试。
- 开始时为全部快照题建立答案行，空答为 NULL，防止漏判未作答题目。
- 选择题存稳定选项 ID，判断题存布尔，简答存文本。false 是有效判断答案，不能当作空答；全空白文本视为空答。
- 完成评分时 is_correct 等价于 score == 满分，部分分为 false，未判为 NULL。
- 更新使用版本检查；忽略客户端提供的分值、对错或评分状态。

### attempt_question_order — 作答展示顺序

attempt_id FK → exam_attempt、exam_question_id FK → exam_question、display_order INTEGER、option_order JSONB。

联合主键 (attempt_id,exam_question_id)，UNIQUE(attempt_id,display_order)。option_order 为快照选项 ID 的完整排列。每次作答生成一次，刷新／接管保持不变，新一次可重新随机。

### grading_task — 整卷阅卷任务

id、attempt_id FK → exam_attempt UNIQUE、assigned_teacher_id FK → user NULL、status(UNASSIGNED/PENDING/IN_PROGRESS/COMPLETED/VOID)、grading_revision、first_review_completed_at NULL、completed_at NULL、assigned_at NULL、version、通用时间。

- 有未完成人工评分的有效答卷才建任务；全空简答自动零分，无需人工任务。
- 初次分配按答卷数均分，在事务中锁定考试并确定分配名单；正常批次教师任务数最多差一份。重试不重建既有任务。
- first_review_completed_at 为空时仅指定教师能评分；首次整卷阅完后其他激活教师也可改分。
- 重开任务保留首次完成时间，不误恢复为全局独占；原教师可用时继续跟进，否则管理员改派。
- 当前完成要求所有题目按目标评分修订判完，历史首次完成不代表当前重新判分已完成。

### grading_history — 不可变评分历史

id、answer_id FK → stu_answer、grading_revision、actor_id FK → user NULL、method(AUTO/MANUAL)、old_score NULL、new_score、old_is_correct NULL、new_is_correct、old_comment NULL、new_comment NULL、reason NULL、created_at。

记录首次评分、人工改分、自动重判。系统 actor 可空，人工改分必须有原因。评分、历史、本次总分及任务完成状态一致提交。

## 6. 错题标记、上传资源与审计

### mistake_annotation — 错题学习标记

user_id FK → user、answer_id FK → stu_answer、mastered BOOLEAN DEFAULT false、note TEXT NULL、通用时间；联合主键 (user_id,answer_id)。

错题资格来自查询，不复制题干或答案。标记归答案所有者；即使存在标记，仍检查公布、允许回看、资格／作答有效、未满分。撤回或改满分后隐藏标记，不删除历史。

### uploaded_asset — 本地资源

id、uploader_id FK → user、storage_key UNIQUE、original_name、media_type、size_bytes、created_at。

不接受客户端指定存储路径。资源不可原位覆盖，题库和快照可共享不可变图片；已有考试引用的资源不能清理。资源经授权接口访问，不暴露任意磁盘路径，不把解析图片作为公共静态资源暴露。

### audit_event — 业务审计

id、actor_id FK → user NULL、action、entity_type、entity_id UUID、reason NULL、before_data JSONB NULL、after_data JSONB NULL、created_at。

覆盖审核、身份更正、班级维护、资格补入／撤销／恢复、考试发布／撤回／取消、阅卷分配／改派、评分依据更正、结果公布／撤回、停用／重置。禁止记录密码、Token 和验证码；含标准答案的审计只供后台授权查询。

## 7. Redis 与后台任务

### session_cleanup — 提交后会话清理任务

2026-09-23 首轮整改由 `0002_session_cleanup` 新增。字段：`id`（UUID 主键）、`user_id`（用户外键）、`revoke_before_version`（可空认证版本阈值）、`clear_password_rate`、`attempts`、`last_error`、`created_at`、`last_attempt_at`、`completed_at`。`(completed_at, created_at)` 索引用于查询未完成任务。

业务变更与任务同事务提交；提交后尝试交付，失败仍保留业务成功事实。版本阈值仅清理旧会话，避免迟到补偿误删新密码会话；任务不保存密码、Token 或带凭据的异常消息。运维命令 `retry-session-cleanups` 可重复执行，完成标记与重试记录单独提交，不重放业务审计。

### 会话与后续考试任务约定

- Redis 保存 Session（sid、user_id、auth_version、创建／活动／绝对到期时间、refresh_token_hash）、限流、刷新协调和 ARQ 队列。
- JWT 10 分钟，Session 空闲 2 小时、绝对 12 小时；Redis 不可用时认证失败关闭，不绕过校验。
- 停用／重置时递增数据库 auth_version 并撤销会话；访问检查 Session 及当前用户状态／版本，防止 Redis 清理延迟导致旧凭据继续访问。
- Refresh Token 为安全随机值，服务端只存摘要，原子轮换；前端协调跨标签页刷新，旧 Token 不得重用。
- 作答、答案、资格、页面令牌摘要和评分以 PostgreSQL 为准，Redis 丢失不导致答卷丢失。
- 事务提交后入队；扫描到期作答、已提交未判完答卷、已结束待分配考试补投任务，覆盖提交成功但入队失败的窗口。
- 不用 Redis 过期通知或 API 进程内临时任务作为唯一自动交卷机制。

## 8. 查询与事务约束

1. 最终成绩：先在有效 SUBMITTED 作答中取 attempt_no 最大的一次，再判断 GRADED；禁止先过滤已判完再取最后一次。
2. 学生结果：本人、RESULTS_PUBLISHED、ASSIGNED、非 VOID；答案、解析和错题还要求 allow_review。
3. 成绩统计使用每人最后一次提交，错题覆盖全部允许回看的有效提交。
4. 限定考试应考数为当前 ASSIGNED 资格数，缺考为其中从未有有效作答者；公开考试无固定应考分母，不算缺考／参考率。进行中、待批改单列，不当零分。
5. 工人写回评分前检查 VOID、资格与目标修订，防止过期任务覆盖新评分或复活废弃作答。
6. 公布检查在考试事务锁下进行：考试结束、有效作答全部提交、当前目标修订全部判完、人工任务完成。判分、撤销、更正遵循一致协调方式。
7. 典型索引：exam(status,end_at)、exam_participant(exam_id,status)、exam_attempt(exam_participant_id,attempt_no DESC)、stu_answer(attempt_id,grading_status)、grading_task(assigned_teacher_id,status)、audit_event(entity_type,entity_id,created_at)。
8. 更正单题只令受影响题目的评分失效；未受影响的已判题分继续有效。答卷的目标修订与汇总状态同步推进，全部依赖的题分完成后才能标记该答卷的新修订 GRADED，不能因全局版本变化强迫无关简答重复阅卷。

## 9. 相对原始草案的变化

- 明确 UUID、密码哈希、时区时间；补全两类 profile，移除单一教学班设想。
- exam 的 paper_id 改为只追踪来源的 source_paper_id，新增 exam_question；stu_answer 指向快照题。
- 支持公开考试首次建立资格、撤销后全部作答废弃、历史次数保留和最后一次提交成绩。
- 新增审核、指定阅卷教师、整卷阅卷任务、评分历史、错题标记、上传资源与审计。
- 不以单个 source_type/source_id 表达多来源持续授权，资格来源作为审计信息保留。
