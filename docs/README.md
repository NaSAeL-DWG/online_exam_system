# 项目文档

本项目是在线限时考试系统。迭代 1、首轮前后端优化、迭代 2 教师考试准备、额外前端整体重构、迭代 3 限时作答与可靠提交，以及迭代 4 自动判分和人工阅卷已完成。实际范围与验证结果见实施计划及验证记录；完整结果公布、学生成绩历史／回看和分析仍按后续迭代实施。

建议阅读顺序：

1. [领域术语](../CONTEXT.md)：统一试卷、考试快照、答卷、最终成绩等含义。
2. [需求规格](./需求规格.md)：用户故事、权限、业务规则、技术约束和 AC01—AC27 验收场景。
3. [数据库表结构](./数据库表结构.md)：身份、快照、作答、阅卷、审计的逻辑字段、约束及查询原则。
4. [实施计划](./实施计划.md)：迭代顺序、待办和实际进度。
5. [本地运行](./本地运行.md)：依赖、环境变量、迁移、启动和管理员恢复。
6. [迭代 1 验证记录](./迭代1验证记录.md)：测试边界、实际执行与验收范围。
7. [第一轮问题检查](./第一轮问题检查.md)：迭代 1 后端架构与一致性问题、原始证据和修复跟踪。
8. [后端架构设计规范](./后端架构设计规范.md)：已确认生效的模块内三层结构、依赖方向、事务、ORM 与接口契约规范。
9. [第一轮优化实施记录](./第一轮优化实施记录.md)：2026-09-23 前后端整改分工、接口约定、实际验证及提交记录。
10. [迭代 2 验证记录](./迭代2验证记录.md)：共享题库、试卷、考试快照和资格管理的实施进度、TDD 证据及后续验收边界。
11. [前端重构迭代](./前端重构迭代.md)：追加的全新前端设计、结构约定、范围与实际验证。
12. [迭代 3 接口契约](./迭代3接口契约.md)：学生考试、作答页面权限、逐题保存、提交及 worker 的协作边界。
13. [迭代 3 验证记录](./迭代3验证记录.md)：限时作答、页面接管、队列故障补处理、迁移和实际验收结果。
14. [迭代 4 接口契约](./迭代4接口契约.md)：自动判分、人工阅卷和后台恢复协作约定。
15. [迭代 4 验证记录](./迭代4验证记录.md)：本轮 TDD、状态一致性修复、浏览器与迁移验收证据。

需求以已确认的规格为准，数据库文档是对应的实现设计。后续修改需同步更新受影响的规则、模型与验收项，不以代码已实现某个行为反向替代需求确认。
