# 文档中心（Documentation Hub）

**中文** | [English](README.en.md)

欢迎来到 **在线限时考试系统** （[GitHub 仓库](https://github.com/NaSAeL-DWG/online_exam_system)）的文档中心。

为了让你用最短的时间找到需要的内容，我们将全部正式文档按 **“你是谁、你要做什么”** 梳理为三大核心板块与快速阅读路线。

---

## 快速阅读路线（按角色选入口）

- **刚拿到项目，想在本地跑起来体验**
  1. 先按 **[快速启动指南 (`quick-start.md`)](quick-start.md)** 配好环境、拉起后端 API、Worker 和前端。
  2. 如果不想手动一条条建题建号，直接看 **[一键生成演示数据 (`demo.md`)](demo.md)**，几分钟内生成含教师、学生和多场不同状态考试的完整环境。
  3. 打开浏览器，对照 **[三端角色操作指南 (`user-guide.md`)](user-guide.md)** 体验出题、考试、批卷和查分。
- **准备接手代码、修 Bug 或开发新功能**
  1. 先花 5 分钟读一遍 **[核心业务术语词典 (`../CONTEXT.md`)](../CONTEXT.md)**，彻底分清“题库题目、试卷、考试快照、答卷、最终成绩”的区别。
  2. 阅读 **[架构设计与开发规范 (`development.md`)](development.md)** 以及前后端工程专项说明（ **[后端维护指南 (`../backend/README.md`)](../backend/README.md)** · **[前端开发指南 (`../frontend/README.md`)](../frontend/README.md)** ）。
  3. 涉及前端界面改动时，对照 **[UI 视觉设计规范 (`ui-design.md`)](ui-design.md)** 保持 C3 视觉与无障碍一致性。
  4. 写完代码后，按 **[测试与验证指南 (`testing.md`)](testing.md)** 跑通对应的 Pytest 集成测试与 Playwright 浏览器测试。
- **负责日常部署、数据备份、故障排查**
  1. 查阅 **[日常运维与故障恢复 (`operations.md`)](operations.md)**，掌握启停顺序、Alembic 升级回滚、数据库备份、管理员重置密码与 Worker 手动补偿命令。
  2. 查阅 **[系统日志与安全审计 (`logging.md`)](logging.md)**，了解怎么在管理后台筛选日志、开启 15 分钟临时 DEBUG 采集以及管理服务器日志文件轮转。
