# 额外迭代：前端整体重构

日期：2026-09-30。状态：实施中。业务基线：`6ef6692`。

## 目标与范围

用户要求全新设计现有前端，而非在原布局上更换颜色。覆盖迭代 1、2 的全部已交付界面：登录、注册、身份审核、账号安全、人员与教学班，以及题库、试卷、考试快照和资格管理。由两名 GPT-6.1-sol（xhigh）子代理分工实施，主代理负责文档、整合、浏览器验收与提交推送。

保留现有公开 API、权限、分页、会话与冲突处理；允许复用正确的领域逻辑，重建页面模板、应用布局、视觉体系和前端职责结构。学生作答、阅卷、成绩功能仍属于实施计划的后续迭代，不以假统计、无效按钮或演示数据冒充已交付能力。

## 设计验收

- 登录页以“账号登录”为唯一主标题和主要视觉重点；不再让欢迎语、英文眉签或宣传标语压过当前任务。
- 所有页面遵守“页面任务 → 主要操作 → 工作内容 → 补充说明”的信息层级。状态、警告、危险操作与普通操作有明确区分。
- 使用统一的中性浅色画布、石墨导航、青绿强调色、细边框、间距和字体层级。品牌表达克制；不叠加无意义大卡片、巨幅营销文案和伪造仪表盘。
- 应用导航按业务分组、按当前账号实际权限展示。考试详情的配置、题目、参考资格清晰分区，后续迭代可在既有结构内添加工作区。
- 桌面优先，同时检查 390 px 小屏下的表单、导航、表格、弹窗和操作；允许数据表格局部横向滚动，不允许整页被固定宽度撑开。
- 保留可访问名称、语义标题、键盘焦点、加载／空数据／失败／保存状态；移动导航可打开、关闭并访问当前业务。

## 结构约定

- API 模块继续负责通信契约与类型；认证状态和 Cookie 刷新仍集中处理。
- 设计 token 与 Naive UI 主题集中管理，不在页面散布颜色数值或用大量全局组件选择器覆盖主题。
- 应用布局、导航声明与业务页面分离；共用页面标题、面板、状态标签、图标只承接实际复用需求。
- 复杂题目编辑、试卷编排、考试配置和资格管理按业务职责拆分；页面负责组合和用户操作入口，避免一个文件同时承担所有编辑器和请求流程。
- 关键逻辑保留中文注释；不为未来假设引入插件系统、万能表单或多层转发包装。
- 淘汰文件移动到 `.deletedfiles/frontend-rebuild-20260930/`，不直接清除；不提交本地凭据、数据库、报告或用户自有 `AGENTS.md`。

## 测试与验收方式

沿用已确认的 Playwright 浏览器公共交互边界。新增登录语义、工作入口、移动导航和编辑流程的必要测试，逐切片执行 red → green；纯视觉通过真实页面截图检查，不为每个 CSS 属性编写断言。

此次覆盖全部前端页面，最终进行一次完整前端浏览器回归、TypeScript／生产构建、格式检查，并检查桌面与窄屏截图。后端未改业务时不重复整套后端测试；浏览器流程继续连接真实 PostgreSQL、Redis 和 API。修改后的选择器必须继续验证原业务含义，不能删除断言来隐藏回归。
