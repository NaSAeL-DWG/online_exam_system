## 测试边界与约定

- 核心测试边界：FastAPI HTTP API + 真实 PostgreSQL/Redis；不要用 SQLite 替代对锁、唯一约束、JSONB 和时区的关键验证。
- 判分集合逻辑、舍入可做小范围纯函数测试；并发／幂等／截止边界用集成测试。
- Playwright 等浏览器测试工具在前端搭建时锁定，重点覆盖注册审核、考试与结果公布，不为每个样式写测试。
- 文档修改只需链接、格式与规则一致性检查，无需运行尚不存在的业务测试。
- 不要求每次全量测试；新修改涉及的风险通过后再进入下一步，避免重复运行无关检查。
