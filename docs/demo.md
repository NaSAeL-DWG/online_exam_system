# 可重复演示数据

演示命令通过系统公开 HTTP 接口创建数据，复用正常审核、开始、提交、评分和公布规则，不直接修改数据库时间，也没有跳过权限的演示接口。使用独立命名空间保留已创建对象，可重跑核对；不会清空数据库。

## 运行

先按[快速启动](quick-start.md)迁移数据库、初始化管理员并启动 API。使用开发或专用演示环境，准备以下私有环境变量：

| 变量 | 用途 |
|---|---|
| `DEMO_ADMIN_LOGIN` | 已有管理员账号，可回退使用 `ADMIN_LOGIN_NAME` |
| `DEMO_ADMIN_PASSWORD` | 管理员密码，可回退使用 `ADMIN_PASSWORD` |
| `DEMO_PASSWORD` | 本命名空间所有演示教师／学生的密码，由操作者提供 |

可以把变量放入忽略的 `.local/demo.env`，以 Bash 可 source 的形式保存。特殊字符需要正确引用；不要复制真实密码到 README 或命令参数。

```bash
cd backend
set -a
source ../.local/demo.env
set +a
uv run python -m app.demo \
  --base-url http://127.0.0.1:18000 \
  --namespace demo-v1 \
  --manifest ../.local/demo-v1.json \
  --window-seconds 120
```

命令需要等待真实短考试窗口结束，默认示例约数分钟。窗口可调整但最低 30 秒；慢机器请增大窗口。密码不通过参数传递，输出仅列命名空间、账号映射和业务对象标识，不输出密码或答案。只需身份与班级时可追加 `--stage identities`，之后用相同命名空间和 manifest 运行完整阶段。

## 数据与演示顺序

| 内容 | 演示用途 |
|---|---|
| 3 位教师、6 位学生、2 个班级 | 多教师协作、学生多班、缺考及资格撤销 |
| 四种题型及 100 分试卷 | 共享题库、快照与客观／人工判分 |
| 已公布限定考试 | 多次作答，较低的最后一次得分成为最终成绩 |
| 已公布公开考试 | 无固定应考分母，成绩与错题反馈 |
| 禁止回看的已公布考试 | 只开放总分，禁止答案与细分表现 |
| 最后一次待判考试 | 最终成绩待定，不回退上次得分 |
| 结果更正中考试 | 已撤回结果，学生暂不能查看 |
| 资格撤销与整场取消记录 | 作答失效、保留历史事实 |
| 可作答、未开始和草稿考试 | 继续体验学生参考及教师准备流程 |

在命令输出中查找 `t1`—`t3`、`s1`—`s6` 的实际 `login_name`，密码使用运行时的 `DEMO_PASSWORD`。建议先以教师查看考试与统计，再以学生查看历史、错题、分析，最后进入可作答考试体验保存与交卷。账号名称和考试标题带命名空间标记，便于与手工数据区分。

## 重跑与保留

同一命名空间配合原 manifest 续跑。已完成的数据不会每次重置为初始分数、重置密码或覆盖手动备注；命令遇到不相容状态会明确报错，应核对现状或用新的命名空间重新演示。私有 manifest 记录进度和对象标识，保留它以支持中断后恢复。

历史成绩在执行时通过真实短窗口产生，不能伪造往年记录。可作答考试会随真实时间到期，重跑不是无限延长既有考试；需要新的实时场景时使用新命名空间。不要把演示账号用于真实学生，项目不提供自动删除整个命名空间的清库功能。
