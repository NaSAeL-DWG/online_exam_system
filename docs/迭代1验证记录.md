## 实际运行环境

- Windows：Node 24.12.0、npm 11.6.2、uv 0.10.7、项目 Python 3.13.14、PostgreSQL 18.3。
- WSL Ubuntu 24.04：Redis 8.8.0；独立密码保护实例由 Windows 通过本地端口访问。
- PostgreSQL 55432：`exam_dev` 用于浏览器联调，`exam_test` 用于 HTTP 集成测试，`exam_migration_check` 用于迁移回退及 CLI 验证。没有修改原有 5432 实例。
- Redis 16379：DB 0、15、14 分别服务上述独立用途。运行配置和随机凭据位于忽略的 `.env` / `.local/`，未提交。
- 前端依赖由 `package-lock.json` 锁定；后端由 `uv.lock`、`.python-version` 与 Python 版本范围锁定。因 TypeScript 7 与当前 vue-tsc 的兼容问题，实际采用 TypeScript 5.9.3。

## 红绿证据

| 切片 | 实际失败 | 修复与通过结果 |
|---|---|---|
| 注册与受限登录 | 初始真实数据库测试发现模型与迁移枚举名称不一致 | 对齐 PostgreSQL 枚举，首个 HTTP 切片通过 |
| 全局登录名唯一 | 重复学号在事务 `flush` 阶段报错，未返回业务冲突 | 捕获事务约束错误，重复注册返回 409；跨角色/身份更正冲突保持原资料 |
| 班级归档 | 已归档班级仍可通过 PATCH 替换负责教师 | 成员修改统一检查归档状态，相关 HTTP 回归通过 |
| 审核与账号恢复 | 待审核账号的状态修改可能绕过审核；停用恢复语义未闭合 | 只有停用恢复可按最近审核映射状态；未通过者回到待审核，禁止直接激活 |
| 注册页面 | Playwright 等待姓名输入框超时，页面尚未实现 | 实现注册表单、CSRF 和成功反馈，真实注册流程通过 |
| 首次改密 | 改密后继续读取已撤销会话，界面未正确完成重新登录 | 显式清理客户端身份并返回登录页，新密码完整流程通过 |
| 班级成员联调 | 浏览器“加入学生”请求缺少 `role`，真实 API 返回 422 | 请求明确发送 `role: STUDENT`，多教师、加入学生、归档流程通过 |

新增行为测试与针对性修复以小切片推进；格式化及环境初始化没有为实现细节单独编写测试。基础提交 `ff377f2` 通过 8 项 API 测试，后续认证与权限回归纳入最终 18 项测试。
