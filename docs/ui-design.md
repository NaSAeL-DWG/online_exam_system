## 一、核心设计理念

考试系统不是花哨的营销落地页，我们的视觉设计围绕四个词展开：**锐利、严肃、秩序明确、任务优先**。
- **不抢戏**：去掉装饰性渐变、弥散发光和大面积浮夸阴影。常态界面以浅灰画布（`#F6F7F9`）衬托纯白内容面板（`#FFFFFF`），让学生的题干与作答区、教师的待批答卷与打分区永远处于视觉中心。
- **克制而硬朗的几何边界**：侧边栏导航按钮与左侧 `3 px` 选中指示条采用**严格直角（`0 px` 圆角）**；内容卡片与普通控件采用 `0 ~ 4 px` 小圆角；下拉弹出层仅用克制阴影表达层级，加载骨架屏采用 3.2 秒周期的短白光横扫动画。

## 二、五级界面信息权重（什么最显眼？）

在一场紧张的限时考试里，如果页面上所有按钮和标签都涂成五颜六色，反而会让考生抓不住重点。我们将界面元素严格划分为 5 个优先级：

| 视觉优先级 | 典型界面内容 | 设计处理规则 |
| :--- | :--- | :--- |
| **1. 异常与紧急预警**<br>（仅在发生时最高） | 答案保存失败、考试时间即将耗尽、多页面接管冲突 | 在操作区紧邻位置用暗红或琥珀色醒目提示原因与下一步操作；**正常答题时绝不常驻占用最高视觉权重** |
| **2. 当前核心任务区** | 学生的题目正文与答题框、教师的待阅学生答案与打分框 | 分配最大的版面空间、最舒适的字号行距与最高对比度 |
| **3. 考试控制与进度** | 开始/继续考试、倒计时、已保存状态、答题卡、交卷、发布考试/公布结果 | 位置固定好找；每个任务区只设一个蓝色主按钮（`#2164CE`）；**“交卷”与“上一题/下一题”严格分区，防止手滑误触** |
| **4. 辅助决策信息** | 考试起止时间、时长、剩余次数、未答题目数、阅卷进度、成绩状态 | 紧挨着对应操作按钮，用清晰的标签与等宽数字展示 |
| **5. 全局支撑信息** | 左侧主导航、列表筛选栏、个人账号资料、常规统计、管理后台入口 | 保持清晰可读，但采用低饱和中性色，绝不喧宾夺主 |

### 各角色工作台设计重心
- **学生首页**：一上来先看“正在进行中的考试（带实时只读倒计时）”和“即将开始的考试 / 最近学习记录双栏”，而不是堆砌一堆花哨图表。
- **学生作答页**：隐藏左侧全局导航栏，进入专注作答布局（左侧题目主栏 + 右侧 `268 px` 答题卡），顶部浓缩展示姓名、学号、截止时间、倒计时与退出/交卷按钮。
- **教师评分页**：同样隐藏全局侧栏，采用 `1248 px` 居中专注工作区（左侧看题目、学生答案、评分依据与改分历史，右侧 `300 px` 面板打分写评语）。
- **成绩展示页**：一眼分清“本场最终成绩（取最后一次有效提交）”与“历次作答记录”，待批改或未公布状态用中性灰诚实提示，绝不按 0 分渲染。

## 三、色彩体系与语义映射（C3 方案）

全站建立 **4 个十阶主色族（50 ~ 900）+ 1 个十阶辅助中性灰**，所有颜色均写入 `frontend/src/styles/tokens.css` 与 `frontend/src/design/theme.ts`：

| 色族名称 | 核心代表色值 | 在系统里专门负责什么？ |
| :--- | :--- | :--- |
| **清亮蓝（Primary Blue）** | Blue 600 `#2164CE` | 主按钮（开始考试、保存、提交）、当前选中题号、选中答案边框、输入框焦点内边框、侧栏选中定位条 |
| **松绿（Success Green）** | Green 700 `#1C5038` | 答案“已保存”反馈、交卷完成收据、阅卷已完成、错题“已掌握”标签、成绩及格标识 |
| **琥珀（Warning Amber）** | Amber 800 `#573B14` | 考试临近截止时间预警、交卷前未答题数量提醒、需要人工关注的待处理提示 |
| **暗红（Danger Red）** | Red 700 `#752936` | 答案保存失败告警、错题错误选项标识、取消考试/撤销资格等不可逆危险操作按钮 |
| **辅助中性灰（Neutral）** | 画布 `#F6F7F9`<br>正文 `#202020` | 承载 85% 以上的常态背景、白色卡片边框、表头、正文与次要说明文字；**“已标记待检查”按钮专门采用深灰底 `#3A3A3A` + 白字实心旗，不占用琥珀预警色** |

## 五、视觉与交互验收标准

后续新增或修改前端页面时，请对照以下清单自检：

1. **首屏三问**：打开页面第一眼，能不能立刻看懂“当前在处理哪场考试/哪个对象、处于什么状态、下一步主按钮在哪”？
2. **对比度达标**：普通正文与背景对比度至少达到 **4.5:1**，输入框边框与焦点状态对比度至少达到 **3:1**。
3. **非颜色唯一依赖**：不能只靠红绿颜色区分对错或状态，必须同时配有文字标签、图标（如对勾、感叹号、旋转加载圈）或边框粗细变化，确保色弱用户和键盘操作用户清晰可辨。
4. **双端零横向溢出**：在 **1440px / 1280px 桌面端** 和 **390px 手机端** 宽度下，页面均不得出现整页横向滚动条（超宽表格必须在表格容器内部局部横向滚动）。
5. **真实数据诚实展示**：后端接口没有提供的统计字段（如考前未暴露的题型分布、公开考试的缺考分母），前端绝不拿假数据硬凑，统一用真实字段或清晰的空态说明呈现。
