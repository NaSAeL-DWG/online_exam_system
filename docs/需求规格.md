# 在线限时考试系统需求规格

版本：v1.0；确认日期：2026-09-20。

状态：用户已完成需求访谈并确认摘要；本文是可实施、可验收的完整规格。迭代 1 的身份与基础工程已交付，实际完成范围和测试结果以实施计划为准，后续迭代不视为已实现。

关联文档：[领域术语](../CONTEXT.md)、[数据库表结构](./数据库表结构.md)、[实施计划](./实施计划.md)。后续变更应同时更新相关规则及验收项。

## 1. 目标与范围

系统用于课程项目／毕业设计，面向一个教学机构，提供从共享题库、预设试卷、考试发布到多次限时作答、判分、人工阅卷、结果公布及学习反馈的完整闭环。

前后端分离，电脑端优先。前端 Vue + Vite + TypeScript、Vue Router、Pinia、Naive UI、ECharts；后端 FastAPI + SQLModel + PostgreSQL，Redis + ARQ。优先使用异步 I/O；本地直接运行，不配置 Docker 作为第一版交付要求。

第一版不包含：多机构租户隔离、教师私有题库、随机抽题组卷、多张试卷合并、代码执行判题、个人补时／暂停、摄像头监考、强制全屏／切屏处罚、批量导入导出、PDF 导出、站内通知、短信或邮件验证码实际发送与验证、学生错题重新练习判分。

邮箱／电话验证仅预留接口，不启用真实验证或自助找回；不伪造成功状态。后续启用需补独立实现和验收。

## 2. 用户故事与权限

### 2.1 用户故事

| 编号 | 用户故事 |

| US05 | 教师可共同维护四种题型，按科目、难度、知识点筛选，关闭不再新增使用的题目。 |
| US06 | 教师可手动挑题组成预设试卷，调序并设置分值，供多场考试复用。 |
| US07 | 教师可从一张试卷创建独立考试快照，编辑考试草稿而不影响原试卷。 |

| US09 | 学生可查看自己可参加的考试，阅读说明后主动开始并消耗一次机会。 |
| US10 | 学生可限时答题、查看保存状态，断线恢复或主动接管已有作答。 |
| US11 | 学生可在次数和时间允许时再次作答，最终成绩采用最后一次提交。 |
| US12 | 系统可在到期时提交已保存答案，自动判客观题及空答。 |
| US13 | 指定教师可接收平均分配的整卷人工阅卷任务，评分并填写评语。 |

| US16 | 学生可查看已公布成绩、各次作答记录，在允许回看时查看答案解析。 |
| US17 | 学生可查看错题、记录备注、标记已掌握，并查看个人表现图表。 |
| US18 | 教师可查看考试进度和成绩统计，发现待批改、缺考及薄弱题目。 |
| US19 | 教师可撤销参考资格或取消考试，令相关作答失效且保留审计记录。 |
| US20 | 管理员可在指定教师失效时重新指派任务，避免阅卷流程停滞。 |

## 3. 身份、审核与账号恢复

### R-IDENTITY

- 统一 user 基础表，一账号一种角色，资料表一对一；学号和工号分别唯一，统一登录账号全局唯一。
- 学生登录账号为学号，教师为工号，管理员为预置账号。管理员账号默认一个，由初始化脚本写数据库，无自助或后台新增入口。
- 学生注册必填真实姓名、学号、邮箱、手机号、密码。密码仅存 Argon2id 哈希。
- 待激活学生仅能访问自身审核状态、必要资料及申请相关接口，不能参加考试或访问正常业务数据。
- 审核拒绝有原因，允许修改后重新申请；审核状态独立于账号停用状态。教师创建后直接激活，临时密码须首次改密。
- 已激活后的学号、姓名由管理员更正。第一版修改联系方式验证当前密码，但不把联系方式标记为已验证。
- 停用立即撤销登录访问和继续答题权限。作答保留，截止时正常交卷；恢复账号不重置截止时间或次数。
- 第一版无自助验证码找回。管理员人工核验后分配临时密码并撤销旧会话，下次登录强制修改；管理员密码由本地运维命令恢复。
- 验证预留接口可固定返回明确的功能未启用错误（建议 HTTP 501 + VERIFICATION_NOT_ENABLED），不得设置 verified 状态或发放重置凭据；不得接受固定万能验证码。

## 4. 教学班、题库与试卷

### R-CLASS

教学班是成员组，管理员创建并关联负责教师，允许多名教师和学生多班。关联教师可从已激活学生中添加、移出成员，无需学生确认。组成员变化不影响已独立建立的考试名单。归档保留关系历史，不再用于维护成员和补入考试。

### R-QUESTION

- 四种题型：单选、多选、判断、简答。选择题 2—8 个选项；单选一个正确答案，多选至少两个；判断固定真／假。
- 题干必填，题干／解析支持 Markdown、图片、公式、代码块；简答题参考答案和解析可选，学生简答仅纯文本。
- 科目必填，难度默认中等，知识点标签可选。图片本地上传，资源不可原位覆盖，快照不能因题库图片替换而变更。
- Markdown 渲染禁用或清理不可信 HTML，图片接口检查文件类型、大小和访问权限，避免共享题目内容执行脚本或解析资源提前泄露。
- 关闭题目仅禁止新增到试卷或考试草稿；原有试卷关联保留，仍可随原试卷复制到新考试但须提示。既有考试和历史不受影响。
- 共享编辑检查版本，检测覆盖冲突。归档代替删除，历史引用及图片须保留。

### R-PAPER

试卷是预设题目集合，无考试名单与考试时间。第一版手动选题、调序、逐题赋分，同一试卷不重复同一道题。归档试卷不能用于创建新考试；题库更新可影响后续复制时取到的试卷内容，已建考试不会联动。

## 5. 考试快照、生命周期与资格

### R-SNAPSHOT

- 创建考试时选择一张试卷，立即复制所有题目内容、选项、标准答案、解析、分类、顺序、分值；不是在发布时才创建快照。
- 草稿可增删题、调序、修改内容和分值，均只改变考试自身。
- 发布后锁定题目及开始／结束时间、时长、次数、多选评分模式、乱序、回看和及格线等配置。
- 尚无人开始可撤回草稿再编辑；有人开始后不得按常规编辑改变题干、选项、分值或考试配置。
- 更正标准答案或简答评分依据须专门操作、保留旧依据及原因，重判受影响有效答卷；已公布时先撤回结果。

### R-EXAM-STATE

| 操作 | 前置条件 | 结果 |
|---|---|---|
| 创建 | 有可用来源试卷 | DRAFT，生成独立快照 |
| 发布考试 | 配置完整；含简答时有激活的指定阅卷教师 | RELEASED，开放详情与对应资格 |
| 撤回考试发布 | 尚无人开始作答 | DRAFT |
| 开始／继续／超时提交 | RELEASED 且满足资格、时间及次数约束 | 改变作答状态，不另建考试进行中状态 |
| 公布结果 | 已结束、所有有效作答提交且判完、人工任务完成 | RESULTS_PUBLISHED |
| 撤回结果 | 已公布，记录原因 | RELEASED，学生显示结果更正中 |
| 取消考试 | 未取消，记录原因 | CANCELLED，废弃全部作答和任务，不可恢复 |

时间阶段由 start_at/end_at 推导。结果发布与考试发布是不同操作，不能用同一个按钮或含糊状态表示。

### R-AUDIENCE

- PUBLIC 面向全部已激活学生，首次实际进入答题流程时幂等建立资格；仅浏览详情不消耗次数。
- RESTRICTED 可按班级展开当前学生、单独补入，合并去重。一个学生在一场考试只有一个资格。
- 班级新增／移除成员均不联动资格，不实现多来源撤销推算。
- 撤销资格可在已有提交后执行；同场全部作答标记 VOID，任务作废，正常记录／成绩／错题查询排除，审计保留。
- 公开考试同样尊重显式 CANCELLED 资格，不能再次创建资格绕过。
- 按班重复补入不自动恢复已撤销资格。显式恢复不复活旧作答，也不重置已使用次数；额外补考另建考试。
- 已公布后撤销资格即时排除该学生相关结果，其他学生公布结果不受影响；本人仍可看到资格撤销提示。

## 6. 限时作答与保存

### R-ATTEMPT

- 点击开始才占用一次机会；同场有未提交且未到期的作答则恢复，不新建。后台尚未处理的到期作答应先收尾。
- 每份作答独立计时：deadline = min(started_at + duration,end_at)。例如 14:00—16:00、时长 60 分钟，15:30 开始则 16:00 截止。
- 前端只展示倒计时，服务端决定时间合法性。关闭页面、断网不暂停；不能通过改设备时间延长。
- 手动或超时提交都消耗次数；未超 max_attempts 且仍在考试窗口内可再开始，新一次仍受全场截止约束。
- 同一作答仅一个页面可写。登录 Cookie 确认身份，sessionStorage 中的独立页面令牌与数据库激活代次确认写权限；刷新恢复，另开页面主动接管。
- Cookie 不能独自区分标签页；实现须处理浏览器复制标签页可能复制 sessionStorage 的情况，避免两个页面同时继续写入。
- 接管、保存、提交在数据库事务中协调，旧令牌立即失去写权限；令牌不能代替资格、状态和截止时间检查。

### R-SAVE

- 选择题修改自动保存；简答停止输入后防抖保存；支持手动保存，明确展示保存中／成功／失败。
- 当前设备暂存未上传草稿，恢复网络且仍在截止前可重试；草稿绑定用户、考试、作答及答案版本，禁止带到下一次作答或其他账号。
- 页面接管后先读取服务器当前答案，不自动用陈旧本地草稿覆盖新页面已保存答案。
- 手动提交先等待保存成功；空题列出后经确认可提交，不强迫填写无意义文字。
- 到期无条件提交服务端已保存答案；截止后不接受离线补传，空白自动零分。未上传内容需向学生明确提示未计入。
- 提交后答案不可修改。重复提交返回既有结果，不新计次数；并发保存不能在提交完成后写入。
- 题目／选项乱序默认关闭，可分别配置。每次开始保存展示顺序；选项以稳定 ID 传输，展示字母不能作为判分身份。

## 7. 判分、阅卷分配与改分

### R-SCORING

| 类型／模式 | 规则 |
|---|---|
| 单选、判断 | 完全正确满分，否则零分 |
| 多选 EXACT | 正确选项集合完全相同才满分，少选／错选零分 |
| 多选 PARTIAL | 无错选时：所选正确数 ÷ 正确总数 × 满分；一位小数；任何错选或未选零分 |
| 简答 | 非空答案人工评分，范围 0—满分，支持一位小数及评语；空白自动零分 |

部分分示例：正确 A/B/C、满分 6，选 A 得 2 分，选 A/D 得 0 分。拒绝无效、重复选项 ID，不能利用重复 ID 增加部分分。判断答案 false 是合法答案。

每题保留评分状态、是否满分、得分、评语和历史；全部题目判完才汇总本次得分。更正时更新版本，旧后台任务不能覆盖新标准或人工评分。

### R-GRADING-TASK

- 考试发布前选择阅卷教师；含简答至少一名，纯客观题无需指定。
- 客观题提交后可先自动判分。考试结束、到期作答交卷并完成空答自动判分后，分配剩余人工阅卷。
- 一份提交答卷为一个任务，所有非空简答交同一教师；多次提交分别建任务，即使最终成绩只取最后一次，也须完成全部有效答卷。
- 按答卷数量平均分配给指定且仍激活的教师，正常初次分配数量最多差一份；无可用教师则待指派，不擅自扩展名单。
- 全空简答已自动零分，不需人工任务。分配重试不得复制任务或覆盖已完成工作。
- 首次整份阅完前，仅指定教师能评分；首次整份阅完后，其他激活教师可修改评分。已评一道题不代表整份首阅完成。
- 并发评分使用版本检查，冲突提示重新读取，不静默覆盖。改分记录人、时间、前后值、原因，重新汇总本次得分。
- 指定教师停用时未完成任务等待管理员改派，保留已完成题分与审计；原教师失去修改权限。
- 撤销资格／取消考试时任务作废；重判客观题自动处理，简答标准更正重开任务并保留首次阅完事实。

### R-FINAL-RESULT

先选该学生最后一次有效提交，再检查是否判完，取其本次总分。不是最高分，也不能取最近一次已判完成绩替代。

例如第一次 90 分、第二次 60 分，最终为 60；第二次待批改，则最终待批改而不是 90。VOID 作答不参与，但仍占已消耗次数。

## 8. 公布、错题与统计

### R-PUBLISH

- 整场统一公布，前提是考试已结束、有效作答全部提交并按当前评分依据判完、人工任务完成。
- 发布前学生仅可看提交／待批改等状态，不得从 API、图表、错题、导出或图片地址取得未公布成绩、正确答案和解析。
- 公布后学生可看本人各次得分及最终成绩；正确答案、解析和错题同时受 allow_review 限制。
- 首阅完成后的人工改分、标准答案更正若涉及已公布结果，须先撤回，学生显示结果更正中，相关成绩／分析／错题隐藏；更正后再次人工公布。
- 查询实时校验状态；撤回不可能撤销学生先前已看到的内容，但后续请求必须受限。

### R-MISTAKES

错题来自全部已公布、允许回看的有效提交中未满分的题，含部分分、零分与空答。保留每次错误及考试快照，后次做对不删除前次错误。支持科目／题型／知识点筛选、备注和已掌握标记；标记不改变成绩。重新判为满分的记录不再属于错题。

### R-ANALYTICS

- 教师查看当前考试的参考、提交、缺考、待批改人数及平均／最高／最低分、及格率、分数分布、逐题得分率。
- 人数按学生去重，多次提交不重复计人数；阅卷任务和作答次数另计。成绩统计只采用每人最后一次有效提交。
- 限定考试应考数为当前有效名单；缺考只在结束后判定，为没有有效作答者。公开考试无固定应考分母，不计算缺考或参考率。
- 未提交或待批改不能默认为零分；教师发布前统计需显示已判完样本数和待批改人数。无已完成样本时显示暂无数据，不显示伪零分。
- 及格默认满分的 60%，考试草稿可配置百分比；得分达到阈值即及格。平均分／及格率分母为纳入统计且完成评分的最终作答人数。
- 逐题得分率 = 纳入统计的最终作答该题得分之和 ÷（人数 × 该题满分）。总分为快照题分之和。
- 学生查看自己各场最终成绩的得分率趋势、按题型的得分率（得分和／满分和）、知识点错题分布；所有成绩分析仅使用已公布且有效数据。
- 知识点错题分布沿用错题可见性，按错误作答记录计数，一题多标签可分别计入，图中说明该口径。禁止由统计接口绕过 allow_review 泄露题目判分详情。
- 不提供他人具体成绩／排名，不做跨班比较。教师整体可查学生记录，但界面不引入未经设计的跨班分母。
- 第一版打开页面时查询数据库汇总，无“生成分析”按钮，无额外统计处理服务；改分重新公布后的下一次查询反映最新结果。

## 9. 认证与可靠性设计

### R-AUTH

- Access JWT 含 user_id、session_id 等身份信息，有效 10 分钟；每次请求检查签名、过期、Redis Session、当前用户状态／auth_version。
- Session 空闲 2 小时、绝对 12 小时；正常认证操作维持活跃。重新登录和刷新不改变考试时间。
- Refresh Token 为随机值，服务端仅存摘要，轮换时原子消费，前端协调多请求和多标签页续期，旧凭据不得复用。
- 登录凭据放 HttpOnly Cookie；修改数据请求做 CSRF 防护。生产 Secure Cookie + HTTPS；本地开发使用受控开发配置和 Vite API 代理，不能全局关闭生产安全选项。
- Redis 故障时提示重试，不绕过登录检查；PostgreSQL 答案保留。退出撤销当前 Session，重置／停用撤销全部旧会话。
- 密码哈希放受控线程池，登录与后续验证预留限流。临时密码只允许改密／退出等必要动作，不能先进入正常考试。

### R-ASYNC

- FastAPI 使用异步接口，SQLModel 结合 AsyncSession、异步 PostgreSQL 驱动、redis.asyncio；不得在事件循环执行阻塞驱动和重型哈希。
- 本地独立运行 API 和 ARQ worker，PostgreSQL 是业务状态依据。定时扫描到期作答、待判分、待分配工作。
- 业务事务提交后入队，持久状态扫描补偿数据库提交成功但 Redis 入队失败的窗口；重启可恢复。
- 超时扫描可能晚于 deadline 执行，但截止后保存必须立即拒绝；自动交卷使用截止前服务端收到的答案。
- 自动判分、任务分配、交卷支持重复触发，使用唯一约束、锁、修订号和状态检查防重；任务更新前重新验证资格和 VOID 状态。
- 基础 UI 对网络或任务故障显示可理解状态；ARQ 失败可重试，不能以后台异常把未判完答卷误记完成。
- 约 100 名同时在线学生是待压测的设计目标，不是当前已验证性能承诺；实际阈值和环境随实施记录。

## 10. 验收场景

以 API + 真实 PostgreSQL／Redis 的集成为主，纯判分规则补小范围单元测试，前端补少量完整流程。测试观察外部行为，不依赖内部函数调用次数。

| 编号 | 场景与预期 |
|---|---|
| AC01 | 学生待激活不能参考；拒绝后可重申；教师通过后可访问；停用后旧会话立即失效。 |
| AC02 | 多教师共享题库；非关联教师不能维护某班学生；学生不能访问他人答卷。 |
| AC03 | 同学生从两个班和单独添加只得一个资格；班级成员变化不联动名单。 |
| AC04 | 公开考试首次开始幂等建资格；显式撤销后不能利用公开入口绕过。 |
| AC05 | 创建时快照隔离；之后改题库／原试卷不影响考试，改考试草稿也不回写来源。 |
| AC06 | 关闭题不能新增组卷，但既有试卷可带提示复制；既有考试仍可正常作答。 |
| AC07 | 并发点击开始只有一次 IN_PROGRESS、只计一次；恢复未提交作答不额外计次。 |
| AC08 | 迟到按 min 截止；断网不暂停；截止后上传拒绝，扫描延迟也不能多答。 |
| AC09 | 手动交卷提示空题但确认可交；超时交卷不被空题阻塞；判断 false 正常判分。 |
| AC10 | 重复提交、保存与提交竞争不产生重复次数或提交后改答。 |
| AC11 | 页面接管后旧页面不能保存／提交；普通刷新恢复；复制标签页不能造成双写。 |
| AC12 | 乱序后选项 ID 正确判分，刷新顺序不变，新次可不同。 |
| AC13 | 多选两模式及小数舍入正确，重复或未知选项不被接受。 |
| AC14 | 第二次低分取低分，第二次待批改不回退第一次成绩。 |
| AC15 | 考试结束后按整份答卷平均分配，全部有效尝试都处理；空答不建人工任务。 |
| AC16 | 首阅前其他教师不能改分，整份首阅后可以；并发改分提示冲突并保留历史。 |
| AC17 | 指定教师停用进入待改派；管理员改派保留已有题分，旧教师失去权限。 |
| AC18 | 结束前／有未提交／未判完不能公布；公布后学生才看到成绩，allow_review 控制答案及错题。 |
| AC19 | 撤回结果后所有相关学生查询隐藏；重判后重新公布更新成绩和分析。 |
| AC20 | 撤销资格令所有历史尝试废弃、任务作废；恢复不复活历史或恢复次数；迟到任务不能写回。 |
| AC21 | 取消整场不可恢复，不计统计／错题，审计保留。 |
| AC22 | 错题含多次错误和部分分；后次做对不抹除前错，改满分后不再显示本条。 |
| AC23 | 多次作答不重复统计人数；公开考试无缺考统计，无样本不伪报零分。 |
| AC24 | Redis 入队失败／worker 重启后扫描补处理；重复交卷／判分／分配不重复写业务结果。 |
| AC25 | Redis 故障不绕过认证；重置撤销旧凭据；刷新轮换正确，CSRF 请求被拒绝。 |
| AC26 | 验证预留接口明确未启用，不发验证码、不标记已验证、不发放重置权限。 |
| AC27 | 学生答题、详情、图片及统计响应不提前泄露密码哈希、标准答案、解析或他人成绩。 |
