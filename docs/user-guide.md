# 三端角色操作指南

**中文** | [English](user-guide.en.md)

系统分为 **学生、教师、管理员** 三种角色。所有角色共用同一个登录入口，使用各自的 **学号、教师工号或管理员账号** 登录。

### 通用交互贴士

- **首次登录与忘记密码**：管理员新建的教师账号或重置后的账号使用的是 **临时密码**，首次登录时系统会强制引导修改密码。第一版暂不支持短信/邮件验证码自助找回，忘记密码请联系管理员人工核验后重置。
- **表单提示与防误关保护**：表单填写有误时，错误原因会用中文直接标在对应输入框下方，点击提交会自动定位到第一个出错的位置。密码框下方的“强/中/弱”指示条仅供参考，确认密码框会实时提示两次输入是否一致。在编辑题目、试卷、考试或评分时，如果改了一半没保存就点返回或关弹窗，系统会弹窗提醒，防止手滑丢数据。

## 一、学生端：参加考试与考后复盘

### 1. 注册账号与等待审核
1. 在登录页进入 **学生注册**，填写学号、真实姓名、邮箱、手机号和登录密码。
2. 提交后账号处于 **待审核** 状态，此时登录后只能查看审核进度。
3. 等待教师或管理员审核：审核通过后即可进入完整的学生工作台；如果被退回，页面会展示拒绝原因，修改资料后可重新提交申请。

### 2. 考前准备与开始作答
1. 从 **我的考试** 列表点进某场考试的 **考试详情**，先看清考试起止时间、个人作答时长和允许作答次数。
2. **只看详情不会扣除考试次数**。只有当你真正点击 **“开始考试”** 按钮时，系统才会为你创建一份新答卷并启动计时；如果你之前已经点过开始且还没交卷，按钮会变成 **“继续作答”**，点进去直接接着上次的进度答。

### 3. 限时答题、自动保存与多页面接管
1. **自动保存机制**：选择题切换选项后立即自动保存；简答题在你停笔一小会儿后自动保存，你也可以随时点手动保存。**请以页面显示的“已保存”状态为准**——仅仅留在当前浏览器本地草稿里、还没同步成功的内容，不算服务器已收到的答案。
2. **倒计时规则**：你的截止时间取 **“个人作答时长”** 和 **“整场考试结束时间”** 中更早的那一个。倒计时由服务器统一控制，**断网、关掉浏览器、甚至重启电脑都不会暂停计时**。一旦到点，系统不再接收新上传的草稿，后台会自动拿服务器上已保存的答案帮你交卷。
3. **刷新与换设备接管**：答题中途按 F5 刷新可以直接恢复进度。但为了防止多个页面互相覆盖答案，**同一份答卷同时只允许一个页面拥有保存权限**。如果你换了台电脑或新开了一个标签页，页面会提示你点击 **“主动接管”** ——接管后，旧页面立刻变成只读状态；接管时请先核对服务器已保存的答案，再继续作答。

### 4. 手动交卷与多次作答
1. 答完题点击 **交卷** 时，系统会先确保正在保存的答案同步完毕，并帮你列出还没填的空题做最后确认。
2. **一旦确认交卷，本次答卷即刻锁定，不能再改**。如果这场考试还在开放时间内，且老师设置了允许多次作答、你还有剩余次数，可以再次发起新的一次作答。

### 5. 查成绩、回看答卷与错题复盘
1. **为什么交完卷还没看到分数？** 刚交完卷只展示提交收据。考试还没结束、老师还没批完简答题、老师还没点“公布结果”，或者老师正在撤回更正成绩时，成绩都不会对外显示，这属于正常业务规则而非系统故障。
2. **最终成绩怎么算？** 当老师公布成绩后，你可以在 **考试历史** 里看到每次作答的得分和本场 **最终成绩**。请特别注意：**最终成绩严格取你“最后一次有效交卷”的分数，而不是取最高分**。如果你考了两次，第二次的简答题老师还没批完，那么你的最终成绩会显示为“待批改”，系统绝不会拿第一次的旧分数顶替。
3. **答卷回看與错题本**：
   - 如果老师开启了 **允许回看**，你可以逐题查看自己的答案、标准答案、解析和老师评语，同时系统会自动把未拿满分的题目收进 **我的错题** （历次有效作答的错题都会保留，第二次做对了也不会把第一次的错题记录删掉）。你可以在错题本里写复习笔记、标记“已掌握”，并查看 **学习分析** 图表。
   - 如果老师设置了 **禁止回看**，成绩公布后你只能看到自己的总分，无法查看具体题目、解析、错题本和细分知识点表现。
   - 如果你的考试资格被撤销或整场考试被取消，相关作答会标记为失效，不计入成绩与错题。

## 二、教师端：从出题组卷到阅卷公布

> **共享协作说明**：题库、试卷、考试配置以及教师侧的答卷列表对 **全体激活教师共享**。如果两个人同时改同一道题或同一份配置，后保存的人会收到“版本冲突”提示，此时请刷新页面核对同事的修改，防止互相覆盖。系统采用“关闭/归档”代替物理删除，确保历史考试记录永远不断链。

### 1. 学生审核与教学班维护
- 教师可以审核学生的注册申请。
- 教学班由管理员创建并关联负责教师（一个班可配多名老师，一个学生也可进多个班）。教师关联到某个班级后，即可添加或移出该班学生。
- **注意**：修改教学班成员名单，**不会** 自动改动已经创建好的考试参考名单。

### 2. 准备题库、组卷与发布考试
1. **共建共享题库**：支持创建单选题、多选题、判断题和简答题，按科目、难度、知识点分类。题干和解析支持 Markdown、数学公式与图片上传；简答题的学生作答区为纯文本。如果某道旧题不再使用，将其设为“已关闭”即可限制新试卷选用，不影响已经引用它的旧试卷和历史考试。
2. **编排共享试卷**：从题库挑题、调整题序、设置每题分值（支持小数）。 **“试卷（Paper）”只是一份可重复使用的题目模板**，不包含开考时间和考生名单。
3. **创建考试与独立快照**：选择一份试卷创建 **“考试（Exam）”** 时，系统会立刻把试卷里的题目深拷贝一份，生成专属于这场考试的 **考试快照（Exam Snapshot）**。从这一刻起，哪怕别人再去改题库原题或原试卷，也完全不会影响你这场考试；反过来，你在考试草稿里微调快照，也不会回写污染原题库。
4. **配置考试规则與名单**：
   - 设置开考/结束时间、单次作答时长、允许作答次数、多选题给分规则、题目/选项乱序、是否允许考后回看及及格线。
   - **只要试卷里包含简答题，就必须指定至少一名激活状态的阅卷教师**。
   - **参考范围**：选“公开考试”则全体激活学生都能考；选“限定考试”则可以按教学班批量导入或按学号单独补入学生（系统会自动去重；如果某个学生之前被撤销了资格，重复按班导入不会自动恢复，需要单独点恢复资格）。
5. **发布考试**：检查无误后点击 **发布考试**。发布后核心配置锁定；只有当 **还没有任何学生点击开始作答** 时，才允许撤回发布重新改配置。如果点击“取消考试”，整场考试将不可恢复地作废，所有已答记录转为废弃状态。

### 3. 批改简答题、公布与更正成绩
1. **何时分配阅卷任务？** 学生交卷后，客观题（单选、多选、判断）和空白简答题由系统自动判分。等到 **整场考试时间结束，且所有有效答卷都完成自动交卷和客观题判分后**，后台 Worker 会把含有非空简答题的答卷，按“整份答卷”为单位平均分配给指定的阅卷教师。
2. **人工阅卷与复核改分**：
   - 老师进入 **阅卷工作台**，打开分给自己的答卷，对照学生答案和评分依据逐题打分、写评语。
   - **首阅权限保护**：在一份答卷第一次全部批改完成前，只有被指派的那位老师能打分；等整份答卷首阅完成后，其他激活教师如果发现判分需要调整，也可以进入该卷修改分数，但 **必须填写改分原因**，每次打分都会留下历史记录。
3. **统计口径说明**：考试详情里的成绩单和统计图表，均按每名学生 **最后一次有效提交** 计算。公开考试因为没有固定应考名单，不计算缺考率分母；待批改的答卷不会按 0 分拉低平均分。
4. **公布结果（Publish Results）**：当考试已结束、所有历史有效答卷（含多次作答的每一次）都批改完毕后，点击 **“公布结果”**，学生端才能查分。请分清： **“发布考试”是让学生能开始考，“公布结果”是考完批完后让学生能看分**。
5. **考后撤回与更正重判**：如果公布成绩后发现某道题标准答案设错了，或某位同学的分数需要复议：
   - 先填写原因执行 **“撤回结果”** （撤回期间学生端会自动隐藏该场成绩、错题与分析，防止看到错误数据）。
   - 修改人工给分，或者直接 **更正考试快照里的标准答案/评分依据** （系统会自动对受影响的题目重新判分，保留无关题目的原有得分）。
   - 全部重判和复核完成后，再次点击 **“公布结果”** 即可。

## 三、管理员端：组织管理与异常兜底

管理员负责全站身份权限、组织架构搭建以及异常情况的兜底处理：

- **教师与教学班管理**：创建教师账号并生成临时密码；创建教学班、指派负责教师、维护班级学生成员。
- **学生账号与身份核验**：审核学生注册；启用或停用账号；在人工核验学生身份后，协助更正学号/姓名或重置临时密码（重置密码或停用账号会立即吊销该用户的旧登录会话，但 **恢复账号不会重置或延长正在进行中的考试倒计时** ）。
- **全局内容与考试监管**：可管理共享题库、试卷与考试配置。为了保持职责分离，**管理员界面不设一线阅卷工作台和直接打分入口**，而是通过考试详情的“阅卷进度与成绩”全局监控批改进度。
- **改派异常阅卷任务**：如果某场考试指定的阅卷老师临时请假或账号被停用，导致阅卷任务卡在“待指派”或无法推进，管理员可在考试进度列表中选择 **“改派任务”**，填写原因后将任务转交给其他激活教师（已批改完的题目分数和历史记录会完好保留）。
- **处理违规或弃考资格**：撤销某名学生的考试资格会使该学生在本场考试的所有作答立即失效；后续即使恢复资格，也不会复活已作废的旧答卷或凭空增加作答次数。如需安排补考，请直接新建一场补考考试。
- **系统日志与操作审计**：从左侧导航进入 **系统日志**，实时查看服务运行日志与敏感操作审计，支持按模块开启 15 分钟临时 DEBUG 采集或管理服务器日志文件落盘，详见 **[系统日志与安全审计](logging.md)**。
- **管理员自身密码恢复**：如果管理员自己忘了密码，需在服务器终端运行 CLI 命令重置，详见 **[日常运维与故障恢复](operations.md#管理员与会话恢复)**。
