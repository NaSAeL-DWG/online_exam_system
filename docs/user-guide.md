# 角色操作指南

登录使用学号、工号或管理员账号。临时密码必须先修改；待审核学生只能查看审核进度与必要资料。忘记密码时联系管理员人工核验，第一版没有短信、邮件验证码或自助找回功能。

表单会在错误字段附近显示中文提示，提交时定位首个需要修改的位置。密码下方的强／中／弱指示仅供参考；确认密码下方会即时提示是否一致。已有输入尚未保存时，关闭编辑器或离开相关编辑页面会提示确认，选择继续编辑可保留输入。

## 学生：参考与学习反馈

1. 注册时填写学号、姓名、邮箱、手机号和密码。等待教师审核；申请被拒绝时查看原因、修改资料并重新提交。
2. 从考试列表进入详情，确认时间、时长和可用次数。阅读详情不会消耗机会，点击“开始”才创建一次作答。存在未提交的有效作答时继续原作答。
3. 选择题修改后自动保存，简答停止输入后保存，也可手动保存。以页面保存状态为准；本地草稿并不等于服务器已经收到。
4. 倒计时使用服务器确定的截止时间：个人时长与整场结束时间取较早值。断网、关闭页面、重新登录都不会暂停。截止后不接受补传，后台使用已保存答案交卷。
5. 刷新可以恢复当前作答。换设备或另开页面时按提示主动接管；接管后旧页面不再有保存权限。先核对服务器答案，再处理本地未保存内容。
6. 手动交卷时等待保存完成，并确认未答题。提交后答案不能修改。仍在考试时间内且有剩余次数时可以再作答。
7. 公布结果后，在考试历史中查看各次得分和最终成绩。**最终成绩取最后一次有效提交**，不是最高分；最后一次待批改时不会拿较早成绩替代。
8. 教师允许回看时，可查看本人答卷与解析，进入错题记录添加备注、标记已掌握，并查看学习分析。错题保留各次错误，后一次做对不会删除之前的错误。

没有成绩并不一定是故障：考试未结束、仍在阅卷、结果未公布或正在更正时均可能不可见。禁止回看的考试公布后仍可显示总分，但不开放答案、解析、错题及细分表现。资格被撤销或考试被取消时，相关作答会失效。

## 教师：从准备到公布

### 账号与班级

教师可审核学生注册，关联到某教学班后可维护该班成员。班级由管理员创建，可关联多位教师，学生可加入多个班。班级成员变化不会自动改变已建立的考试名单。

### 准备题目、试卷与考试

1. 在共享题库创建单选、多选、判断或简答，填写科目、难度和知识点。题干、解析支持 Markdown、公式和图片，简答学生答案为纯文本。
2. 在共享试卷中手动挑题、调序、设分。试卷是可复用题目集合，尚不包含考试时间或名单。
3. 从试卷创建考试，此时立即复制独立快照。以后修改原题或试卷不会联动既有考试，编辑考试草稿也不会回写来源。
4. 设置时间、时长、次数、评分规则、乱序、回看权限及及格线。含简答题的考试需指定至少一名激活的阅卷教师。
5. 公开考试面向全部激活学生；限定考试需要按班级或单独补入学生，系统去重。重复按班补入不会恢复已撤销资格，需显式恢复。
6. 保存并发布考试。发布后配置锁定；只有尚无人开始作答时才能撤回发布。取消考试不可恢复，会废弃全部作答。

题库、试卷、考试及教师侧答卷全体教师共享。界面报告编辑冲突时，重新加载并核对他人的修改，避免覆盖。关闭题目只限制新增使用；旧引用与快照保留。归档代替删除。

### 阅卷与成绩

1. 交卷后系统自动判客观题与空答。考试结束后，所有有效作答完成提交和客观题判分，才向指定教师均分整份人工阅卷任务。
2. 从阅卷工作台打开分配给自己的任务，逐题输入范围内分数及评语。首次整卷完成前只有指定教师能评分；整份完成后其他激活教师也可记录原因改分。
3. 最终成绩和统计按每名学生最后一次有效提交计算。学生第二次待批改时，最终成绩为待批改；全部历史有效答卷仍需阅完才可公布。
4. 在考试结束、全部有效作答判完、人工任务完成后，执行“公布结果”。这与“发布考试”是不同操作。
5. 已公布成绩需要改分或更正依据时，先填写原因撤回结果，再更正／重判，全部完成后重新公布。撤回期间学生的相关结果、错题与分析隐藏。

没有可用的指定教师时，任务等待管理员改派。公开考试没有固定应考人数，因而不计算缺考分母；没有评分样本显示暂无数据，待批改不按零分计算。学习分析统计口径随图表说明展示。

## 管理员：身份与异常处理

- 创建教师并交付临时密码；创建教学班、关联教师、维护成员。
- 审核学生、维护账号状态、人工核验后更正学生学号／姓名或重置密码。重置和停用会撤销旧会话，恢复账号不会重新开始倒计时。
- 管理共享题库、试卷和考试。首次人工阅卷仍须由指定激活教师完成，管理员不能绕过首阅规则直接评分。
- 对待指派或教师失效的阅卷任务填写原因改派。已完成题分与评分历史保留。
- 撤销考试资格会令该学生同场全部作答失效，恢复资格不会复活旧作答或恢复次数；需要额外补考时另建考试。

管理员自身忘记密码需使用本地运维命令，见[运维指南](operations.md)。身份、资格与结果变更具有不同含义，操作前核对确认说明和对象。
