# C3 学生工作台还原复核

日期：2026-11-06。

用户指出正式界面与已确认稿不完全一致。本轮以 `design/ui-redesign/color.html` 的 `student-home` 为参照，核对源码及 1440 px 截图。上一轮虽然完成了共享配色和业务适配，但学生工作台的信息顺序与版式没有完整落地，不能将“主题统一”视作“设计稿还原”。

## 差异与处理

| C3 设计稿 | 上一轮实现的差异 | 本轮处理 |
|---|---|---|
| 问候、日期与考试提示 | 通用“学生工作台”标题及账号状态 | 恢复真实姓名问候、上海日期与考试提示 |
| 当前作答卡，右侧独立浅蓝倒计时区 | 只有考试名称、时间与按钮 | 接入只读作答接口，呈现服务器已保存进度、本次截止、次数与个人倒计时 |
| 接下来的考试／学习记录双栏 | 全宽近期考试列表，缺少学习记录 | 恢复双栏；考试按开始时间排序，成绩与待复习错题读取现有接口 |
| 独立考试提醒 | 放进“我的账号”大卡片 | 移除学生首页账号大卡片，恢复底部考试提醒 |
| 考试空间／学习反馈／个人账号导航 | 学习入口混在工作空间 | 恢复分组、考试工作台名称、学生侧栏宽度与蓝色图标 |

按本轮明确意见，考试详情三张信息卡取消顶部色条，开放及结束态均保留普通细边框。注册与修改密码的字段下不再显示“仅作参考，密码需10—256个字符”；独立“密码要求”栏位于输入区与提交按钮之间，仍保留强度／匹配反馈，校验规则不变。

## 真实数据与边界

- 首页只读作答快照，不调用 `activate`、不消耗考试机会或接管另一个标签页；用 `deadline_at` 和 `server_now` 推算个人倒计时，判断题的 `false` 计为已作答。
- “已保存进度”指服务器快照，不宣称其他标签页的未同步修改已经上传。读取失败显示重试提示，不编造倒计时。
- 当前考试与接下来两场考试从近期 20 条记录中挑选。列表不完整时不显示推测的全局场次数；完整列表仍从“全部考试”进入。
- 学习记录使用现有结果和错题接口，待复习数量采用服务端筛选总数；窗口重新获得焦点时清空旧记录后重读，撤回结果不继续展示旧分数。
- 设计稿中的考试编号、考前题量和学年／学期尚无对应接口字段，本轮不生成示例数据或用 UUID 充当业务编号。因此按已确认版式还原，不宣称所有静态文本和像素完全相同。

## 验证

新增 `student-home-design.spec.ts` 和 `c3-review-details.spec.ts`，验证布局区块、只读请求、倒计时递减、已保存进度、成绩撤回后的清空、卡片边框、密码要求位置以及原有密码长度规则。同步调整原首页测试，保留教师及管理员回归。

1440 px 的 C3 参考截图、学生工作台桌面／390 px 截图与本轮测试证据存放于忽略目录 `.local/ui-c3-alignment/`；密码和考试卡片的 1280／390 px 截图位于 `.local/c3-review-details-verified/`。

最终组合验证：上述两个新增文件、`c3-implementation.spec.ts` 和 `c3-student.spec.ts` 合计 15 项通过，生产构建、格式检查与 Git 差异检查通过。桌面核对重点区与双栏，390 px 核对单栏重排，未出现整页横向溢出。以上是本轮范围的验收，不替代其他页面的逐页还原复核。
