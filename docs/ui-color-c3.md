# UI 配色方案 C3：浅灰画布与纯白面板

> **状态**：已通过用户最终审核，并已完成全站 Vue 前端落地与验证（详见 **[C3 前端落地总览](ui-c3-implementation.md)** 与 **[全站 30 页落实记录](ui-c3-page-rollout.md)**）。
> **离线原型入口**：直接用浏览器打开 [`design/ui-redesign/color.html`](../design/ui-redesign/color.html) 即可体验（点击右上角“配色说明”可查看完整 50 色色板）。

---

## 一、为什么定稿为 C3 方案？

在 UI 改版过程中，我们经历了三轮色彩演进：
1. **[C1 方案](ui-color-design.md)**：采用 `#F4F4F4` 灰底和深蓝 `#1F456F`，整体偏灰暗厚重。
2. **[C2 方案](ui-color-c2.md)**：改为全白背景 `#FFFFFF` 并提亮为清亮蓝 `#2164CE`，但通体全白导致卡片与背景缺乏层次感。
3. **C3 最终方案（本方案）**：将全局工作区画布微调为极浅的冷灰 **`#F6F7F9`**（Neutral 50），而内容卡片、作答区、左侧导航栏与顶栏保持纯白 **`#FFFFFF`**。这样既保留了清爽明亮的视觉感受，又让白色内容卡片自然浮现出清晰的边界层次。

## 二、C3 核心用色与几何规则速查

| 界面区域 / 元素 | C3 定稿视觉规则 |
| :--- | :--- |
| **全局工作区画布与卡片间距** | 采用极浅冷灰 **`#F6F7F9`**（Neutral 50），衬托白色卡片 |
| **内容卡片、作答区、表单面板** | 保持纯白 **`#FFFFFF`**，配 `1 px` 细边框 |
| **左侧导航栏与顶部栏** | 保持纯白 **`#FFFFFF`**，不使用大块深色背景 |
| **主操作按钮、焦点、选中态** | 采用清亮蓝 **Blue 600 (`#2164CE`)**，悬停态 **Blue 700 (`#1A50AA`)** |
| **侧栏导航项与左侧选中条** | **严格直角（`border-radius: 0`）**，选中时左侧展示 `3 px` 直线蓝色指示条 |
| **考试详情顶部三张概览卡** | 统一采用普通细边框，**不加顶部彩色粗横条**；考试结束后整排卡片转为中性灰 |
| **“已标记待检查”按钮** | 常态浅灰底；标记后采用 **深灰底 `#3A3A3A` + 白色文字 + 实心白旗**，与蓝色主操作和琥珀预警色严格区分 |
| **注册与改密页的密码要求** | 独立成栏，放置在**密码输入框与提交按钮之间**，保留实时密码强度与二次确认匹配提示 |

> **色板继承说明**：除 Neutral 50 由 `#FAFAFA` 调整为 `#F6F7F9` 外，清亮蓝、松绿、琥珀、暗红四大十阶主色族与其余辅助灰色阶均沿用 **[C2 完整色阶表](ui-color-c2.md#主色与完整色阶)**。

## 三、对比度与多端验证结论

- **桌面端（1440px）与移动端（390px）布局检查**：工作区浅灰底 `rgb(246, 247, 249)` 与纯白内容卡片层次分明，侧栏按钮计算圆角均为 `0px`，无任何整页横向溢出。
- **无障碍对比度**：次要文字 `#626262` 在新浅灰画布 `#F6F7F9` 上的实测对比度为 **5.69:1**（高于 4.5:1 的正文标准），主按钮白字与 `#2164CE` 对比度为 **5.56:1**，清晰易读。
- **生产前端对齐**：前端已基于本方案完成全站 30 个页面场景的逐页还原，详见 **[C3 正式前端落地 (`ui-c3-implementation.md`)](ui-c3-implementation.md)**、**[学生工作台还原复核 (`ui-c3-alignment-review.md`)](ui-c3-alignment-review.md)** 及 **[C3 逐页落实总表 (`ui-c3-page-rollout.md`)](ui-c3-page-rollout.md)**。
