# UI 配色方案 C3：轻灰衬底与白色内容

日期：2026-11-04。状态：修订完成，等待用户审核。

用户反馈 C2 的通白背景缺乏分区对比，希望保留灰底，但灰底不要太多、太突出。本轮采用 `#F6F7F9` 的很浅灰色衬托工作区和卡片间隔，白色继续用于卡片、侧栏、产品顶栏与评审栏。

## 当前入口

[打开 C3 单文件 demo](../design/ui-redesign/color.html)。左上角版本为 C3，右上角“配色说明”可查看全部色阶。

## 调整范围

| 对象 | C3 处理 |
|---|---|
| 工作区与卡片外部间隔 | `#F6F7F9` 浅灰背景 |
| 卡片、作答区、表单表面 | 保持 `#FFFFFF` |
| 侧栏、产品顶栏、评审栏 | 保持白色，不恢复大块深色 |
| 主按钮、焦点、选中态 | 沿用 C2 清亮蓝 |
| 已结束考试、已标记按钮和语义状态 | 保留已确认的灰色与成功／预警／错误规则 |

辅助灰 Neutral 50 从 `#FAFAFA` 调整为 `#F6F7F9`，用作浅灰画布及常规提示等轻量背景。四个主色族与其余色阶沿用 [C2 色表](ui-color-c2.md)，仍为 4 个主色族各 10 阶，另设 10 阶辅助灰。布局、字体、间距和交互不变，生产代码未修改。

## 验证

- Chrome 1440 px 下检查考试详情、考试作答和成绩详情：工作区背景为 `rgb(246,247,249)`，内容卡片为白色，无整页横向溢出。
- 390 px 下检查考试详情：浅灰与白卡片层次保持，无横向溢出。
- 次要文字 `#626262` 在新灰底上的对比度为 5.69:1，达到本次正文目标；新的 Neutral 50 仍比 Neutral 100 明亮。
- 内联脚本语法检查通过。本轮仅调整背景层次，未重复运行前后端全量测试。

当前待用户确认灰底的强度及分区对比是否合适。
